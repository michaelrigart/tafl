# Tafl v1 Implementation Plan

**Status:** In progress (branch `feat/tafl-v1`). Awaiting Codex's plan review.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Tafl, a keyboard-first macOS 27 window manager. It places windows on a grid,
moves them between displays, handles display changes by fixed rules, applies layouts from a
TOML config file, and keeps its macOS specifics in one layer.

**Architecture:**
- **`Packages/TaflCore`** holds every rule: geometry, placements, actions, the five-stage
  pipeline, applying a frame as a checked sequence of writes, window memory, display-change
  rules, layouts, the config file and shortcuts. It declares the platform interface and
  imports Foundation and TOMLDecoder only.
- **`Packages/TaflPlatform27`** implements that interface for macOS 27 with Accessibility,
  CoreGraphics and AppKit. It holds every private symbol and every `#available` check.
- **The app target, `Tafl`,** is a thin AppKit and SwiftUI shell: composition root, Carbon
  hotkeys, the config watcher, the status item, Settings, the failure overlay, onboarding
  and logging.

**Tech Stack:** Swift 6.4 (Xcode 27.2, macOS 27.2 SDK), Swift Testing, Accessibility
(`AXUIElement`, `AXObserver`), CoreGraphics display APIs, Carbon `RegisterEventHotKey` and
Text Input Sources, ServiceManagement (`SMAppService`), `os.Logger`, `dduan/TOMLDecoder`
0.4.5, XcodeGen pinned in `mise.toml`.

**Spec:** `docs/superpowers/specs/2026-11-01-tafl-design.md`. Read it before any task. After
Task 2 it gains a "Measured on macOS 27.2" section; where that section and "What macOS
allows" differ, the measured section holds.

## Global Constraints

- **Platform and language:**
  - Deployment target macOS 27.0, Swift 6 language mode, complete strict concurrency.
  - Packages use `// swift-tools-version: 6.4` and `.macOS(.v27)`; if `.v27` is not
    defined, use `.macOS("27.0")`.
- **Bundle and signing:**
  - Bundle identifier `com.michaelrigart.tafl`, display name Tafl, `LSUIElement` YES.
  - `CFBundleShortVersionString` is `$(MARKETING_VERSION)` (default `dev`) and
    `CFBundleVersion` is `$(CURRENT_PROJECT_VERSION)` (default `0`). Installed builds stamp
    `YYYYMMDD-HHMM` in local time, no `v` prefix.
  - Not sandboxed. Hardened Runtime on. Ad-hoc signing (`CODE_SIGN_IDENTITY "-"`).
- **Imports:**
  - `TaflCore` imports only `Foundation` and `TOMLDecoder` (exact `0.4.5`). No AppKit,
    SwiftUI, ApplicationServices, Carbon, CoreGraphics-only API, `os` or `#available`.
  - Private symbols, undocumented attributes and `#available` live only in
    `TaflPlatform27`. Each private symbol is resolved at run time with `dlsym`; a missing
    one becomes a fallback and a capability state, never a crash.
- **Paths:**
  - Config: `~/.config/tafl/config.toml`. Tafl writes it only through Create Starter File,
    and never over an existing file.
  - Window memory: `~/.local/state/tafl/memory.json`, version 1.
- **Values:**
  - Accessibility messaging timeout 0.5 s per call (`AXUIElementSetMessagingTimeout`).
  - Recognition tolerance 2 points. "Still at the achieved frame" means within 1 point.
  - Size retry when off by more than 1 point. A size short by less than 30 points in a
    dimension, and never larger, counts as success (terminal resize increments; Task 2
    measures it).
  - Cross-display reapply after 25 ms, unless Task 2 removes it.
  - Display-change quiet period: Task 2's measured value, at most 3 s.
  - First title change counts within 1 s of window creation.
  - Failure overlay shown for 1.5 s.
  - `smaller` never goes below the window's minimum size, or 200 × 150 points when the
    app exposes none.
  - Display identifier: `"<vendor>-<model>-<serial>"` in decimal.
- **Config defaults:** `repeat = "displays"`, `gap = 0` (0–100), `step = 30` (1–500),
  `menu-bar-icon = true`, `launch-at-login = true`, every action on its default shortcut.
- **Coordination:**
  - No `Task.sleep`, `asyncAfter` or timers to let things settle. Sleeps happen only on an
    injected `TaflClock`, for the reapply, the quiet period and the overlay's display time.
  - Every Accessibility call runs on a per-app serial `DispatchQueue`, never on the main
    actor or the cooperative pool.
  - No `NotificationCenter` dispatch between Tafl's own components.
- **Unsafe annotations.** `@unchecked Sendable` and `nonisolated(unsafe)` each carry a
  `// reason:` comment on the same line.
- **Fixed text.** User-facing failures are `FailureKind` values with fixed wording
  (Task 5). A system error description never reaches the overlay, Settings or
  diagnostics; platform code logs it at `.private` and returns the fixed kind.
- **Logging:** `Logger(subsystem: "com.michaelrigart.tafl", category: …)`. Actions,
  failures, display changes and config reloads at `.notice`. Bundle identifiers may be
  `.public`; window titles are `.private`. Nothing is read from an app only to log it.
- **Never:** event taps or synthetic input; writing Apple's preferences (including
  `com.apple.WindowManager`); launching apps; network access or telemetry; any permission
  other than Accessibility; moving a window outside the spec's triggers.
- **Rectangle port.** Port from Rectangle `v2.0.4`, cloned read-only into
  `.superpowers/rectangle-src` (ignored by git). Each port keeps Rectangle's behaviour,
  pinned by tests. Never open Loop's (`MrKai77/Loop`) source.
- **Build and test outside the Claude sandbox.** Prefix every Swift or Xcode command with
  `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`. Don't change `xcode-select`.
  Parallel tasks pass `--scratch-path build/spm-task<N>` to `swift test` and
  `-derivedDataPath build/dd-task<N>` to `xcodebuild`.
- **Generated, never committed:** `Tafl.xcodeproj/`, `build/`, `.build/`.
- **Copy:** English only. Commits and public docs carry no machine details beyond the
  spec's.

## Review Focus

1. **An app that never answers** while a layout or the display-change rules place several
   windows. Its windows fail with "\<App> didn't respond" after the timeout; the other
   apps' windows are placed; a shortcut on another app's window still works meanwhile.
   Tested in Task 15.
2. **No usable focused window:** the desktop is focused, the app has no windows, or the
   focused element is a sheet. The overlay says "No window to move" or "This window can't
   be moved", and nothing is written. Tested in Task 12.
3. **The config file disappears:** deleted, or a symlink whose target is gone. A deleted
   file means built-in defaults; a dangling symlink is an error that keeps the last good
   configuration. Tested in Task 7.
4. **Minimized windows and hidden apps** are skipped by layouts and by the display-change
   rules, so neither unminimizes nor moves them. Tested in Tasks 13 and 14.
5. **A corrupt memory file** (for example after a crash) is moved aside as
   `memory.corrupt.json`, Tafl starts with empty memory and logs it, and a file from a
   newer version is never overwritten. Tested in Task 9.

**Interfaces (Produces):**
- `public struct ScreenPoint`, `ScreenSize`, `ScreenRect` (`Hashable, Codable, Sendable`),
  all `Double`, in one space: Accessibility's top-left global coordinates, y downward.
  `ScreenRect(x:y:width:height:)`, `origin`, `size`, `minX`, `maxX`, `minY`, `maxY`,
  `midX`, `midY`, `func isClose(to: ScreenRect, within: Double) -> Bool`,
  `func intersectionArea(_:) -> Double`, `func contains(_: ScreenPoint) -> Bool`.
- `public struct UnitRect` (`Hashable, Codable, Sendable`): fractions of a visible frame.
  `ScreenRect.relative(to visible: ScreenRect) -> UnitRect`;
  `UnitRect.absolute(in visible: ScreenRect) -> ScreenRect`, rounded to whole points.
- `public struct DisplayIdentity: Hashable, Codable, Sendable` with `name: String`,
  `vendor`, `model`, `serial: UInt32`, and `var identifier: String`
  (`"\(vendor)-\(model)-\(serial)"`).
- `public struct Display: Equatable, Sendable` with `identity`, `frame`, `visibleFrame`
  (already corrected for Dock, menu bar and notch) and `var isPortrait: Bool`
  (`visibleFrame.height > visibleFrame.width`).
- `public struct DisplaySetup: Hashable, Codable, Sendable` with
  `identities: Set<DisplayIdentity>` and `init(_ displays: [Display])`.
- `public struct GridCell: Hashable, Sendable` with `columns`, `rows`, `column`, `row`,
  `columnSpan`, `rowSpan`; `func rect(in visible: ScreenRect) -> ScreenRect`. Edge `i` of
  `n` lies at `visible.minX + (Double(i) * visible.width / Double(n)).rounded()`, the same
  for rows.
- `public enum NamedPlacement: String, CaseIterable, Codable, Sendable`: `left-half`,
  `right-half`, `top-half`, `bottom-half`, `top-left`, `top-right`, `bottom-left`,
  `bottom-right`, `first-third`, `center-third`, `last-third`, `first-two-thirds`,
  `center-two-thirds`, `last-two-thirds`, `maximize` (raw values; Swift cases in
  camelCase). `func cell(portrait: Bool) -> GridCell`. Landscape cells are
  `(columns, rows, column, row, columnSpan, rowSpan)`: halves `(2,1,0|1,0,1,1)` and
  `(1,2,0,0|1,1,1)`; quarters `(2,2,c,r,1,1)`; thirds `(3,1,0|1|2,0,1,1)`;
  first and last two-thirds `(3,1,0|1,0,2,1)`; center two-thirds `(6,1,1,0,4,1)`;
  maximize `(1,1,0,0,1,1)`. On a portrait display, thirds and two-thirds swap columns
  and rows.
- `public enum Gaps { static func apply(_ gap: Double, to rect: ScreenRect, cell: GridCell) -> ScreenRect }`,
  ported from Rectangle's `GapCalculation`: inset every side by `gap`, then give back
  `gap / 2` on each side the cell shares with a neighbour (left if `column > 0`, right if
  `column + columnSpan < columns`, top if `row > 0`, bottom if `row + rowSpan < rows`).
- `public enum PlacementRecognizer { static let tolerance = 2.0; static func recognize(_ frame: ScreenRect, on: Display, gap: Double) -> NamedPlacement? }`:
  the first placement in `allCases` order whose gapped rect is within the tolerance.

  `func reconfigurationBegan()`.

  `func run<T: Sendable>(_ window: WindowHandle, _ body: @Sendable @escaping () async -> T) async -> T?`.
  It cancels the window's running request, waits for it to finish (its Accessibility
  call in flight returns first), then runs `body`; it returns nil when `body` was
  cancelled by a newer request.

**The write sequence** (`write`), the spec's "Applying a frame":
1. Begin a session; a failure returns `.failed(f, lastVerified: nil)`. From then on,
   every exit (a result, a failure, a cancellation or an interruption) ends the session
   exactly once. `expected = start`, `lastVerified = nil`.
2. Order the parts with `WriteOrder`; skip a part already equal to the target.
3. Before each write: if the task is cancelled, or a reconfiguration began, return
   `.cancelled(lastVerified)`; if a frame passed to `observed` since the last check
   differs from `expected` in a part other than the one that was in flight when it was
   observed, return `.interrupted`.
4. Write the part, then read back. The written part takes the value read. The other part
   must equal `expected`'s within 1 point, or be explained by an adjustment in
   `adjustments`; otherwise return `.interrupted` without another write. Every write
   clears `lastVerified`; a read-back that passes its check sets `expected` and
   `lastVerified` to the frame read.
5. After a size-first size write, position at `EdgeAligner.origin(for: target, actualSize:)`.
6. If the size is off by more than 1 point, set `max(target.size, minSize)` once more,
   read back and check, and re-align the position if it moved.
7. Classify, with `aligned = EdgeAligner.origin(for: target, actualSize: achieved.size, visible: targetVisible)`:
   an origin more than 1 point from `aligned` → `.positionRefused(achieved)`; otherwise
   within 1 point of `target`, or short by less than 30 points per dimension and never
   larger → `.placed(achieved)`; otherwise `.sizeRefused(achieved)`.
8. **Reapply:** when `crossesDisplays`, `reapplyDelay` is set and the result is placed or
   size-refused: sleep `reapplyDelay` on the clock (a cancellation ends the request with
   the result so far), then read the frame first. Only if it is still the achieved frame,
   run steps 1–7 again, in a new session, with `start = achieved`; the final result is
   that run's.
- A platform failure after a write returns `.failed(f, lastVerified:)`.

**Interfaces (Produces):**
- `public struct SettleTracker: Sendable`: `init(quietPeriod: Duration)` (asserted ≤ 3 s);
  `mutating func began(at:)`, `ended(at:)`, `windowMoved(at:)`; `var isChanging: Bool`.
  `began` opens a reconfiguration and the next `ended` closes it. `var deadline: Duration?`
  is nil while one is open, else the last input plus the quiet period while changing.
  `mutating func settleIfDue(now:) -> Bool` is true once, when none is open and
  `now >= deadline`.
- `public struct WindowAtChange: Sendable` with `snapshot: WindowSnapshot`,
  `previous: StoredFrame?` (last known on the old setup, frozen when the change began),
  `remembered: StoredFrame?` (last known on the new setup), `isObserved: Bool`.
- `public enum DisplayChangeRules { static func plan(oldDisplays: [Display], newDisplays: [Display], windows: [WindowAtChange], claiming: LayoutDefinition?, gap: Double) -> [MoveRequest] }`,
  all with `source: .displayChange`. Per window, the first rule that applies:
  0. Skipped: fullscreen, minimized, hidden app, not observed.
  1. `claiming` matches it (`LayoutPlanner.entryIndex`) → the layout's placement.
  2. `remembered` on a connected display → `.frame(remembered absolute)` on it.
  3. `previous` on a display no longer connected, recognised there → `.named(p)` on the
     window's current display.
  4. `previous` on a display no longer connected → `.relative(previous.relative)` on the
     current display.
  Otherwise no request. A request whose result equals the current frame is left to the
  pipeline's `.unchanged`, which is how windows macOS restored itself stay put.

### Task 15: The engine

**Depends on:** Tasks 12, 13 and 14 · **Tier:** sp-standard

**Files:**
- Create: `Packages/TaflCore/Sources/TaflCore/Engine/WindowEngine.swift`,
  `Engine/EngineReport.swift`, `Engine/EngineTiming.swift`
- Test: `WindowEngineTests.swift`

**Interfaces (Produces):**
- `public struct EngineTiming: Sendable` with `quietPeriod`, `reapplyDelay: Duration?`
  (Task 2's values).
- `public enum EngineReport: Equatable, Sendable`: `failure(FailureKind, display: DisplayIdentity?)`,
  `layoutApplied(name: String, placed: Int, failed: Int)`, `displayChangeHandled(moved: Int)`,
  `unobservable(bundleID: String?)`, `memory(MemoryLoad)`.
- `public actor WindowEngine`:
  - `init(platform: any WindowPlatform, store: MemoryStore?, clock: any TaflClock, timing: EngineTiming, steps: [any AdjustStep], adjustments: [MacOSAdjustment])`;
  - `func start(config: Config) async`, `func update(config: Config) async`,
    `func perform(_: Action) async`, `func applyLayout(named: String) async`,
    `func save() async`, `func stop() async`;
  - `var activeLayoutName: String? { get }`;
  - `nonisolated let reports: AsyncStream<EngineReport>`.

**Behaviour:**
- **Actions** first check `isAccessibilityGranted()`; without it they report
  `.failure(.permissionMissing, display: nil)` and do nothing else. Otherwise they call
  `pipeline.run(focused, config:, plan:)`, whose plan builds the `ActionContext` from the
  `ResolvedWindow` and the pointer display and calls `ActionResolver.plan`. A failure
  reports `.failure(kind, display:)`.
- **Layout runs** (by shortcut, menu or a display change) run concurrently across apps and
  in order within one app, so a hung app delays only its own windows (Review Focus 1).
  Applying a layout activates it.
- **Events:** a moved or resized event reads the window's frame. While `writer.isWriting`,
  it goes to `writer.observed`; otherwise a frame not at the achieved one is an external
  change. Each frame updates last-known frames for the current setup unless a change is
  in progress, and counts as a window move for the `SettleTracker`.
- **Last-known frames are seeded** from `visibleWindows()` at start, from each created
  window, and from every visible window after a display change's rules have run (for the
  new setup), so a window nobody touched still has one.
- **New windows** with an active layout are placed by its matching entry
  (`.newWindow(layout:)`); `TitleCheck` decides the one later attempt, which plans with
  the current config and places the window again only when the result differs from what
  was applied at creation.
- **Display changes:** `began` freezes last-known frames, tells the writer, and stops a
  layout or rules run in progress. At settling, if the setup differs from the one before
  the change: the active layout ends; each `WindowAtChange` is built from the frozen
  old-setup frames and the new setup's remembered frames; the rules run; a claiming
  layout becomes active. Recording stays frozen until the rules have run, and only then
  are the new setup's frames seeded. Start with a changed setup follows the same order.
- **Reloads** never move a window: `ActiveLayout.reconcile`, new entries for later windows.
- **Start:** load memory (reporting `.memory`), start observing, and run the rules once if
  `lastSetup` differs from the current setup. **Stop** and **save** persist memory.
- **Unobservable apps** are reported once and left out of rules and layout new-window
  placement.
