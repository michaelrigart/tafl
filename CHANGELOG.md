# Changelog

All notable changes to Tafl are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions are release times,
`YYYYMMDD-HHMM` in the maintainer's local time: a version says when a release was made, not
whether it is compatible with the one before. Each section says what changed.

## [Unreleased]

### Added

- Tafl v1: place windows on a grid (halves, quarters, thirds, maximize and more) and move them
  between displays from the keyboard.
- Layouts defined in the config file apply themselves when their displays connect, and put new
  windows of their apps in place.
- A Settings window that shows your configuration, and an option to launch Tafl at login.
- An app icon and a menu bar icon.
- Install with Homebrew: `brew install --cask michaelrigart/tap/tafl`.
- Releases are signed with a stable certificate, so the Accessibility permission you give Tafl
  survives updates.
